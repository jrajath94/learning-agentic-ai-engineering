Principles

A line you repeat belongs in a file the tool actually loads.

Anthropic's best-practices page says a repeated correction should become a hook, because a prompt is advice. The hook skeleton is kit/claude/settings.json. The repeated test rule is the TDD skill at SHA abeeaf95660ba9e8b7c753eb38f441ca707a8823.

See the shape first

Sequence and state

1. Mechanism

Context is the window. A skill body stays out until the description matches. A CLAUDE.md line is in every turn. A hook runs after the tool, whether the model remembered the line or not. Codex's sample caps project docs at 32 KiB, so a principle that does not fit is not a principle Codex will see. Thariq Shihipar, 28 Sep 2026, said to start without CLAUDE.md and add a line only after the same failure repeats, because lines do not transfer across models.

2. Artifact

Do not add a principle page to the kit. Add one line to the file the product loads, or one command to the hook in kit/claude/settings.json. kit/prompts/adversarial.md asks the second model to run a command that tries to falsify the claim, and to paste the output.

3. Worked example

The counter demo is the smallest instance. The failing assertion is the principle made executable: inc(1) must be 2. The first run printed the assertion error. The second printed ok. A markdown sentence "write correct code" would not have failed the first run.

4. Failure modes

  • A 200-line CLAUDE.md of principles nobody re-reads. Thariq's rule, on the talks page, is to add a line only after the same failure repeats.
  • The same paragraph pasted into CLAUDE.md, AGENTS.md, and GEMINI.md, then edited in only one.
  • A hook whose command is still {{FORMAT_COMMAND}}. It fails every write and you disable hooks.

5. Exercise

Find one correction you typed twice this week. If a shell command can check it, put that command in kit/claude/settings.json in place of {{FORMAT_COMMAND}} and delete the sentence. If not, add one line to the loaded file and delete it from the prompt you were pasting.

6. Your stack

Bank code gets the hook in kit/claude/settings.json and the test, not a longer prompt. Research notes can live in the prompt. A principle that only one model obeys is a model habit. Put it in the file that model loads, and do not expect the other seat to inherit it.
