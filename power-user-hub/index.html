How to read this

  2. Treat a primary row as the origin document. A secondary row is someone else's careful write-up. An echo repeats an origin and is not new evidence.
  3. Sentences marked hypothesis or synthesis are not observations of a named person's production system.
  4. Copy prompts only from the vault. Each one names who published it.

Where the practice actually differs

They separate judgment from muscle

Antigravity's Orchestrator pairs a planning model with an implementation model. Lauren Tan's pstack routes code, prose, and judgment to one model and a review panel to three. OpenAI's dots pick among models and can hand the coding to Codex. The chat habit is one model, one thread, one sitting.

C23 C47 C29

They make "done" a check, not a sentence

Anthropic's docs put branch protection and a human merge above the model's summary. Superpowers deletes code written before a failing test. pstack's interrogate skill keeps a finding only when a run proves it. Boris Cherny's January write-up had Claude drive the Chrome extension until the UI worked.

C49 C44 C48 C22

They leave a machine running, with a permission story

Duet, dots, and Grok Bot all keep working on a cloud computer and message you when a decision is needed. The power-user move documented by the vendors is not "let it send." It is a schedule plus an approval stop on send, pay, sign, and delete.
