Muse Code

Turn Contributor mode off, then stop at /plan.

Install line from the 5 Aug 2026 post and the docs: curl -fsSL https://dev.meta.ai/install.sh | bash. No Muse settings git repo was fetched, so kit/muse/README.md has no commit SHA. The pricing page, fetched 20 Nov 2026, says subscriptions default to Contributor mode.

1. Mechanism

/plan is an approval gate. The model can keep planning, but the launch post says the plan waits for you. /grill stress-tests that plan. /goal is the long run. Background agents stay for the session instead of being spawned per step. The event log appends every model call, tool, approval, and edit so a crash can resume. That log is the state. A chat scroll is not.

Contributor mode is a data switch, not a quality switch. Standard Spark is $1.25 per million input tokens and $4.25 per million output tokens. Contributor is $0.10 and $0.20 because Meta may train on prompts, code, files, context, and responses. The docs page still names default model muse-spark-1.2 while the price list also has 1.3. Check muse on the day you run it. Hacker News item 49187575, 5 Aug 2026, 333 points when fetched, links Meta's launch post and adds no second measurement. C289.

2. Artifact

There is no copied settings.json. The artifact is the README plus this prompt, which you type after /plan:

/plan
Bug: {{SYMPTOM}}
Test: {{TEST_COMMAND}}
Do not edit until I approve the plan.

3. Worked example

This environment did not install the Muse binary, so there is no muse transcript. The local red-green script is still the check you name in the plan: sh kit/scripts/tdd-demo.sh prints a failure, then ok. Put that command, or your real test, in the plan. If the plan does not contain the command, do not approve it.

4. Failure modes

  • Contributor mode left on for a bank repo. The pricing page is the warning. Turn it off before the first prompt.
  • /goal with a vague objective. The gate is /plan. Skipping it is how a long event log fills with the wrong edits.
  • Session messaging on Windows. The docs say it is unavailable there.
  • Trusting a resumed log you did not read. Resume is exact about what was appended, not about whether it was right.

5. Exercise

On a machine where muse --version works, run /plan on a bug you understand and approve nothing. Self-check: the workspace is unchanged, git status is clean, and the plan quotes your test command.

6. Your stack

Muse is a separate subscription from the $20 Claude seat and the about $100 Codex seat. Use Muse when you want the event log and the plan gate. Use Claude when you want the verbatim TDD skill. Do not run both planners on the same task. Superpowers can also install into Muse and will try to own the sequence. Pick one.
