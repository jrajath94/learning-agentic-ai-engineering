See the shape first

1. Mechanism

He says December is when his own ratio flipped from mostly typing to mostly delegating, and that he does not think he has typed a line of code since. The limit he names is no longer typing speed. It is how many agent sessions he can keep fed without their edits colliding. He describes a friend with many Codex sessions, about 20 minutes each on high effort, and about 10 repo checkouts, moving work between them in large chunks rather than line by line.

Auto research is the same idea with the human removed from the middle. He wrote a markdown file, program.md, that says what to try next. The loop ran overnight on a small GPT training playground he had already tuned by hand for years. It changed weight decay on the value embeddings and Adam betas. He had missed those. He says the loop found them because the score was objective. If you cannot evaluate, he says you cannot auto-research it. If you push the loop further than the agent can actually do, he says the result is net harmful. Agents are jagged: a request comes back wrong and then the next turns stay wrong.

2. Artifact

program.md is his file. The gist does not include the file. Do not pretend a copy here is his. The prompt you can run is kit/podcasts/karpathy-eval-loop.md. It requires a metric command, a direction, a trial budget, and a forbidden path list. He also says that when Codex quota runs out he switches to Claude, and that unused subscription quota is idle throughput, the way idle GPUs bothered him in grad school. That is a routing habit, not a config file.

3. What he said happened

  1. He already had a hand-tuned training setup. He did not start the loop on an unscored app.
  2. program.md listed the kinds of changes to try: architecture, optimizer, and so on. He called it a rough markdown description.
  3. The loop ran overnight without him in the chat.
  4. It kept changes that improved the training objective. The ones he names are weight decay on the value embeddings and Adam betas that were off, and that interact so one change forces the other.
  5. He treats that as one loop. He says frontier labs do the exploration on smaller models and then extrapolate. He does not claim the overnight run trained a frontier model.

4. Failure modes

  • No metric. He states this as the first caveat. A "make the UI nicer" loop has nothing to keep or revert.
  • The loop edits the scorer. Then every trial looks better. Pin the metric command outside the allowed paths.
  • Two trials that both edit the same file. His friend's setup uses separate checkouts so functionality does not collide. One working tree will race.
  • Going further because the first night worked. He says the system is still jagged and a too-long horizon is net harmful.
  • Calling leftover quota a moral duty. He is talking about his own research throughput. A bank change still needs a person on the diff. Unused quota is cheaper than a bad merge.

5. Exercise

Pick a number you already print, such as pytest duration or a benchmark script. Put that command in the kit prompt. Allow edits only under one directory. Set the budget to 3 trials. Self-check: RESULTS.md has three rows, each with two numbers you can reproduce by running the command on the kept and reverted diffs. If a row has a number you cannot re-run, delete the row and the change.

6. Your subscriptions

He names Claude Code and Codex as the harnesses he switches between when a quota ends. That matches a stack with both a Claude seat and a Codex seat. He does not describe Muse, Antigravity, or Grok Bot in the section that was read. Do not point an overnight loop at a ledger, a customer extract, or a prompt log. The forbidden-path line in the kit file is there because the loop will try anything inside the allowed list.

Where he disagrees with the other episodes

  • Boris, 4 Mar 2026, still reads the plan and still has a person approve the merge. Karpathy's stated goal is to not be there for the next prompt. Those are different jobs. Use Boris when the change is a product diff. Use Karpathy when the score is a command.
  • Thariq, 28 Sep 2026, spends high effort so the model verifies. Karpathy's overnight loop verifies with the metric command, not with more model thought. If the metric is wrong, extra effort will not catch it.
  • He says Codex the coding agent feels dry and does not seem to care what you are building, while Claude feels more like a teammate. That is his taste report, not a benchmark.
