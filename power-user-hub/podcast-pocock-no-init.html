Do not let the agent write the instruction file.

Source: youtube.com/watch?v=9tmsq-Gvx6g. The captions spell the file "claw.md" and "agent.mmd". He means the init file a coding agent writes.

See the shape first

Sequence and state

1. What he said

At 00:00:10: "I am going to recommend that you never ever run this." The "this" is an init command that writes a claw.md or agents.md of codebase documentation. At 00:00:13: if you find one you think an agent created, delete it. He says the file burns tokens, distracts the agent, and goes out of date. He cites a paper whose conclusion, in the captions, is that unnecessary requirements from context files make tasks harder, and human-written context files describe only minimal requirements. C301.

2. Artifact

kit/prompts/pocock-no-init.md. Pair it with the TDD skill you already have, which is a file he published, not an init dump.

3. Exercise

If CLAUDE.md or AGENTS.md in a repo was produced by an init command, move it out of the tree and run one task. Self-check: the agent still finds the test command by reading the repo.
