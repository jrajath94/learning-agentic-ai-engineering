Prompt vault

Open the file. Fill the braces. Do not treat a vendor demo as your prompt.

The files under kit/prompts/ are instructions for this hub. They are not transcripts. The TDD skill next to them is the exception: it is copied from mattpocock/skills at abeeaf95660ba9e8b7c753eb38f441ca707a8823.

See the shape first

1. Mechanism

A pasted prompt is one turn. A skill loads when its description matches. A CLAUDE.md line is every turn. Use the prompt file for the turn, the skill for the loop, and the markdown file for the command you are tired of retyping. xAI's Gmail story and OpenAI's dot story are product copy. They show a shape. They are not logs you can replay.

2. Artifact

  • tdd-loop.md stops before a production diff.
  • review.md asks for a finding with a file, or an explicit none.
  • plan.md and spec.md name files and a check.
  • overnight.md has a stop command.
  • pr-prep.md is the command list before you open a pull request.
  • research.md demands a URL on every material sentence.
  • fan-out.md is for separate checkouts only.
  • adversarial.md looks for a missing test.
  • grok-draft-only.md forbids send.

3. Worked example

Fill tdd-loop.md with the counter. The red output on 20 Nov 2026 was AssertionError: inc(1) should be 2. The green output was ok and a three-line function. If a model replies with a production diff before you have that red output, the prompt was not followed. Run sh kit/scripts/tdd-demo.sh if you want to see the two stages without a model.

4. Failure modes

  • Pasting all ten files into one turn. Pick one.
  • Leaving {{TEST_COMMAND}} in the paste. The model will invent a command.
  • Saving a Grok skill from the draft prompt before you have a draft you would send.

5. Exercise

Run tdd-loop.md on a bug whose failing test you can paste. Self-check: the first reply has no production diff, and the command in the reply is the command you typed.

6. Your stack

The same markdown works on Claude Code, Codex, Gemini CLI, and Muse. Grok Bot gets only the draft file. Antigravity's Orchestrator can take plan.md. Do not give fan-out.md a shared working tree.
