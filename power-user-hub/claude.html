One failing test, then the smallest change that passes it.

1. Mechanism

A skill body is not in the window until the task matches its description. The TDD skill's description names red-green-refactor, so a bug fix can load it without putting the whole file in CLAUDE.md. CLAUDE.md is resident. Anthropic's best-practices page says a line you keep repeating belongs in a hook, because a prompt is advice and a hook runs. kit/claude/settings.json is a PostToolUse hook on Write or Edit. The command is {{FORMAT_COMMAND}} until you set it.

Claude Code 2.1.277, 18 Sep 2026, added this line to the changelog: in a project with no CLAUDE.md, Claude Code reads AGENTS.md instead, and you change that under Project instructions in /config. Source: code.claude.com/docs/en/changelog. 2.1.281, 23 Sep 2026, says that fallback also works on Bedrock, Vertex, Foundry, gateways, and when telemetry is disabled. Hacker News item 49760187 on 18 Sep 2026, 741 points when fetched, links the changelog and does not add a second measurement. If both files exist, do not assume both load. A r/ClaudeAI report said 2.1.312 loaded only CLAUDE.md. That report is archive-backed, not an Anthropic guarantee.

2. Artifact

Install with sh kit/setup.sh from a repo you can change. It refuses to overwrite. Then edit placeholders. The skill text is verbatim. The provenance file next to it has the SHA. Prompt: kit/prompts/tdd-loop.md.

3. Worked example, no model

sh kit/scripts/tdd-demo.sh ran on this machine on 20 Nov 2026. First the test called inc, which returned its input unchanged. Then the function became n + 1 and the same test printed ok.

$ python3 test_counter.py

    assert inc(1) == 2, "inc(1) should be 2"
AssertionError: inc(1) should be 2
exit 1
$ python3 test_counter.py
ok
exit 0
--- counter.py after the green run ---
def inc(n):
    return n + 1

That is the loop the skill names: red before green, one slice. It is not a Claude transcript.

4. Failure modes

  • The test asserts a + b by recomputing a + b. The skill calls that tautological. Use a literal, assert inc(1) == 2.
  • You write every test, then all the code. The skill says that tests imagined behavior. One test, then the code for that test.
  • The hook's command is still the placeholder. It will fail on every write. Put a real formatter in, or delete the hook until you have one.
  • Both CLAUDE.md and AGENTS.md exist and you only edited AGENTS.md. Check /config to see which file this build loaded.
  • Asking which tools are missing. Stephane Derosiaux, 5 Mar 2026, got six subagents and a wishlist, then wrote that the list is training patterns plus tools the product knows how to call. Treat it as a hypothesis, then check the binary yourself. C294.

5. Exercise

In a clone, add one assertion that fails for a bug you can already reproduce. Run the test. Paste the failure into kit/prompts/tdd-loop.md with the seam filled in. Self-check: the first model reply contains no production diff. After you reply green, git diff touches the test and the one function.

6. Your stack

Run this on the Claude Code seat you pay about $20 for. When that cap is gone, the same prompt works in Codex if AGENTS.md holds the test command. Do not point either tool at customer extracts. Five parallel checkouts, the March 2026 Boris pattern, belong on tasks that do not share files. See that episode.
