A name in a changelog is not a workflow. The useful residue is a file, a flag, or a refusal.   • Hook: kit/claude/settings.json. The command string is a placeholder because his formatter is not yours.

3. Worked example

Take Thariq's rule and apply it to the counter. Do not write a CLAUDE.md first. Run sh kit/scripts/tdd-demo.sh. The first failure is AssertionError: inc(1) should be 2. The repeated failure, if you kept a stub, is the line you add: the test command. One line, after the failure, not before.

4. Failure modes

  • Profiling someone because a recap site quoted them. If the primary file was not opened, they are a gap.
  • Copying Boris's five-checkout habit onto one working tree.
  • Treating the May 2025 dollar figure as a 2026 quota.

5. Exercise

Open kit/podcasts/thariq-effort-and-notes.md. Copy it into a scratch repo. Run only the step that does not call a model, which is your test command. Self-check: you can name the timestamp the step came from.
