# Grok Bot kit

xAI has not published a git repo of Bot settings that this pass could copy, so there is no commit SHA. The four permission levels are from the 18 Nov 2026 changelog: Always allow, Auto-review, Needs approval, Blocked.

## Setup

1. Connect one mailbox.
2. Set search or read tools to Always allow.
3. Set send, pay, post, and delete tools to Needs approval.
4. Run one morning draft pass. Send nothing.
5. If the drafts are usable, save the steps as a skill, then attach a schedule. The overview says a repeated task becomes a routine, and a routine skips when the connector is signed out (changelog 1.2.3).

Prompt: `kit/prompts/grok-draft-only.md`.

Do not point a routine at a production ledger. The published examples leave drafts for you to send.
