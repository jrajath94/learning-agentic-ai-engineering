# Gemini CLI and Antigravity kit

`GEMINI.md` is a short project file for your repo. `GEMINI.md.upstream-excerpt` is the opening of the Gemini CLI repo's own file, commit `addc194f5bc414e7134c2bd6a414a40e1b4cbbed`.

Antigravity's changelog (18 Nov 2026) is the source for Orchestrator, `/swarm`, and `/btw`. There is no public Antigravity config repo in the files fetched for this kit, so there is no SHA for an Antigravity settings file. Do not invent one.

## Install for Gemini CLI

```sh
cp kit/gemini-antigravity/GEMINI.md GEMINI.md
```

Fill the placeholders. In Antigravity, put the same facts in the project rules file the app already loads. If you do not know the filename, stop and read the app's settings instead of guessing.

## Run

One task, one check command. Use `/btw` for a read-only question while a turn is running. Use `/swarm` only when the slices do not edit the same files. Orchestrator (Neon), as of the 18 Nov 2026 changelog, plans with Neon and implements with Hydrogen. You still read the diff.
