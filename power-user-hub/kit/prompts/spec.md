# Spec before tickets

Provenance: original synthesis from Matt Pocock's README (fetched 2026-11-20): grill before code, then a spec. The questions below are the ones his TDD skill says to settle first: the public seam.

```text
Change: {{CHANGE}}
Users who hit it: {{WHO}}

Ask me up to five questions, one at a time, about the public behavior.
After I answer, write a spec with:
- the behavior a test can see
- the files you expect to touch
- what will not be built
Do not write code.
```
