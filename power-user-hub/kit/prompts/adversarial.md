# Try to break the claim

Provenance: original synthesis from Lauren Tan's `/interrogate` description in the pstack README (fetched 2026-11-20): keep a finding only when a run proves it.

```text
Claim: {{CLAIM}}
Diff or command: {{DIFF_OR_COMMAND}}

Try to show the claim is false.
Run a command. Paste the output.
If you cannot falsify it, say what command would, and that you did not run it.
Do not edit the project.
```
