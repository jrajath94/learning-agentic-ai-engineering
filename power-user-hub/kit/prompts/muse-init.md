# muse init, and why yolo stays off

Provenance: freeCodeCamp Muse Code course, 26 Aug 2026, https://www.youtube.com/watch?v=b-P5ZQ1NxxE. At 01:49:51 the instructor runs `muse init` and says it writes the project rules file. The captions spell that file "agent.mmd" and "agents.mmd". At 02:36:44 he says `yolo` is the equivalent of full permissions and that bubblewrap, his sandbox, was not installed.

```text
Turn Contributor mode off before the first prompt.
Run: muse init
Read the project file it writes. The captions do not agree on the spelling.
Do not enable yolo.
If a command would leave the sandbox, stop and ask.
```
