# Do not run init

Provenance: Matt Pocock, 24 Feb 2026, https://www.youtube.com/watch?v=9tmsq-Gvx6g, 00:00:10. The captions spell the generated file "claw.md" and "agent.mmd".

```text
Do not run an init command that writes CLAUDE.md or AGENTS.md.
If a generated instruction file is already in the tree, do not follow it.
Read the repo to find {{TEST_COMMAND}}.
Print that command.
Do not edit files.
```
