Every six months, delete CLAUDE.md, the skills, and the hooks.

Source: youtube.com/watch?v=qyPCVqFUQy0, transcript in the harvest, captions. Boris Cherny. The captions say "Claude MD". That is the file CLAUDE.md.

See the shape first

Sequence and state

1. What he said

At 00:04:29 the captions say they deleted 80 percent of the system prompt. At 00:04:38 he says you can pass a system prompt flag and set whatever system prompt you want. At 00:04:50 he names an undocumented environment variable in speech as "Claude Code simple equals one". Running Claude after that, he says, deletes all the system prompts, including from the tools. The spelling of that variable is the spoken form. This page does not turn it into a guessed name.

At 00:06:03 he calls the method an ablation: delete the entire system prompt and bring it back line by line. At 00:06:58, for people using Claude Code rather than building it: every 6 months delete your Claude MD, delete your skills, delete your hooks, and see what the model does. At 00:07:14 he says this is what they recommend for Opus 5, because the model might not need the instructions past models needed. C299 C300.

2. Artifact

The prompt is kit/prompts/boris-ablation.md. It is a hub instruction that follows his order. It is not a file from Anthropic.

3. Failure modes

  • Typing a guessed environment variable name. Use the spoken description, or read claude --help on a machine that has the binary.
  • Deleting the only copy of a hook that encodes a safety rule you still need. He is talking about instructions the new model may already follow. A deny rule for send or pay is not the same object.

4. Exercise

Copy CLAUDE.md aside. Remove it for one task the model has done before. Self-check: if the task still passes the same test, the file was not earning its place. If it fails in a way you have seen twice, put one line back.
