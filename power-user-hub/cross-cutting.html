Cross-cutting

One test command, four instruction files, one person on the diff.

The files that carry the command are CLAUDE.md, AGENTS.md, and GEMINI.md. Muse has no file, only the /plan line in kit/muse/README.md.

See the shape first

Sequence and state

1. Mechanism

Each product loads a different file. C280: Claude Code 2.1.277 loads AGENTS.md only when CLAUDE.md is absent. Codex stops adding project docs at project_doc_max_bytes, 32768 in the sample. Gemini CLI loads GEMINI.md as resident context. The gemini-cli copy at addc194f5bc414e7134c2bd6a414a40e1b4cbbed tells that repo to run npm install, npm run build, and later npm run preflight. Those commands are wrong in a repo that is not that monorepo. Muse waits at /plan if you use the command. Grok Bot does not load any of these. Its constraint is the send-tool permission.

2. Artifact

Run sh kit/setup.sh once. It copies the Claude and Codex files. If a destination already exists, the script prints skip and continues with the next file. Then copy GEMINI.md yourself. Open tdd-loop.md in whichever product you are in. The loop text does not name a vendor.

3. Worked example

sh kit/scripts/verify.sh checks that the kit files exist, then runs the counter demo. On 20 Nov 2026 it exited 0. The demo's first test failed with AssertionError: inc(1) should be 2. After the function returned n + 1, the same test printed ok. Use that pair of outputs as the bar for a model session: a failure, then a pass, then a small diff.

4. Failure modes

  • Editing AGENTS.md while CLAUDE.md exists, then wondering why Claude ignored the edit.
  • Letting Superpowers and the TDD skill both own the sequence. Pick one. Superpowers is mandatory by its own README.
  • A second agent editing the same files the first agent is editing. Parallelism in the Boris thread is separate checkouts.

5. Exercise

Put the same test command in all three markdown files. Ask each tool, one at a time, to print the command and not to edit. Self-check: three replies, one string, git status clean.

6. Your stack

Claude about $20 for kit/claude/skills/tdd/SKILL.md. Codex about $100 for sandbox_mode in kit/codex/config.toml.sample. Google AI Pro for Antigravity's planner and implementer. Muse for an event log and a plan gate. Grok Bot for drafts that are not code. Production stays behind your diff, not behind a second model.
