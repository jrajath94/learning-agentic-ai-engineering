Deep Dives Index

Replication grade pages built from round 3 primary extraction: full text posts, repo files, and podcast transcripts. Each page holds steps, commands, file structures, a worked walkthrough, a checklist, and an application to your work.

The pages

  1. Reed spec pipeline: spec, prompt plan, todo, and the mise task system.
  2. Hashimoto system: six steps, the end of day routine, and the Ghostty AGENTS.md in full structure.
  3. Ball and Amp: self waking agents, the proof demand, Orbs, and instruction evals.
  4. Gas Town: all roles and commands, plus a solo lite form.
  5. Litt: the surgeon model and the explain diff skill, full structure.
  6. Ronacher setup: tool rules, the Makefile log pattern, stack picks with reasons.
  7. Yan news agents: code level multi agent build with FastMCP and tmux.
  8. Cherny: the 13 practices, team tips, Lenny principles, and the YC ablation method.
  9. OpenAI harness: map rule file, docs system, layer law, doc care agent.
  10. Anthropic systems: research swarm, best practice ladder, the C compiler harness.
  11. Skill repos: Pocock, Superpowers, and Caveman file systems.
  12. Podcast systems: compound engineering, voice to issue, the feature capsule, Notion specs.
  13. Lauren Tan fleet: the 15 bot roster, blind evals, and the bot design method.
  14. Mods and evals: harness middleware, the supervisor numbers, and the Hamel method.

How to use this set

Read one page. Run its checklist on a live task the same day. The pages cross link to prompt files in the repo prompts folder, each a full template you can paste and adapt. Depth beats coverage here: one system in your hands beats fourteen in your notes.
