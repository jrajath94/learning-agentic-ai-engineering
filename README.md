## Power User Hub

Source-grounded static notes on Grok, Claude, Gemini, Codex, and Meta Muse live in [`power-user-hub/`](power-user-hub/).

Open them with no build step:

```bash
cd power-user-hub
python3 -m http.server 8765
```

Then visit [http://127.0.0.1:8765/](http://127.0.0.1:8765/). Opening `power-user-hub/index.html` in a browser also works. See [power-user-hub/README.md](power-user-hub/README.md) for the page map, the claim ledger, and the link checker.
