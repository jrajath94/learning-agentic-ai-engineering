# Transfer the method to another repository

Paste one prompt into a read-only session before you assign any edits.
Give a synthetic reproduction and the real contract owner or document.
Use the result to draft one implementation task.

## Filled example

Start from the command that a scheduled evaluation report invokes.
Map the producer, parser, aggregation step, and report consumer.
Identify whether a retry means another delivery or another attempt.
Find a legacy input that must retain its behavior.
Define counters or state that would differ if the fix is wrong.
Propose one implementation scope and one independent test scope.
Keep all files unchanged.
