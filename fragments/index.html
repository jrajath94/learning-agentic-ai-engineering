Open the guide and run one example

Extract the complete archive. Open index.html directly. The chapters, rendered diagrams, fonts, search and exercises work without a connection. The Python workshops use the standard library. The branch exercise also requires Git. Each chapter gives its exact commands and expected observations.

Use Python 3.10 or later. Open a terminal in the folder that contains this page. To verify every supplied local exercise in a fresh output folder, run the command below.

python3 -B scripts/replay-workshops.py workshop-output

Read the relevant chapter before you interpret a result. Some examples intentionally expose a failure or reject a candidate. The run record states the expected exit status for each command.

Compare your result with the recorded run

Open the run viewer to compare the first patch, the held-out retrieval failure and the two retry histories. Screenshots beside the workshop steps show those same records. The social workflow chapter turns accessible posts and transcripts into reproducible tests.

Make a prediction before you run it

Use the first fixture as a paper exercise. Name the state fields. Predict one transition and its output. Run the code, compare the result, and explain the first difference. Then change one input and repeat. Each workshop includes a failure case, a worked trace and exercises with answers.

Use the supplied agent prompts after you understand the local checks. Give your agent one task, the actual input files and an acceptance rule. Review its output against the same tests. Use the reconstruction and transfer checks to find what still needs practice.
